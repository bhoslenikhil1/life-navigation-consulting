# Speak & Settle

A premium dating and relationship guidance brand focused on one-to-one private sessions.

## Overview

This website is designed around a single conversion path:
- Free WhatsApp chat
- One-to-one session booking
- Personalised relationship guidance

## Files

- index.html — main landing page
- call.html — one-to-one session booking page
- contact.html — contact and FAQs
- privacy.html — privacy policy
- terms.html — terms and conditions

## Local preview

Open the site in a browser from the project root or serve it locally with a simple static server.

## Deployment

- Push the files to the GitHub repository
- Enable GitHub Pages
- Keep the live branch configured for the website deployment

## Payment

Use Razorpay checkout for the one-to-one session flow. Update the key in the booking page before production use.

## Branding

The site is built around a warm luxury aesthetic with a strong focus on modern relationship clarity and personal connection.
